# vocab-study

능률VOCA 단어 학습 웹앱. 정적 HTML 두 개로 동작합니다.

- `index.html` — 학생용 (플래시카드 · 객관식 퀴즈 · **주관식 퀴즈** · 단어장 · 즐겨찾기)
- `admin.html` — 선생님용 (학생별 즐겨찾기 · 틀린 단어 · 주관식 인정 답안 관리)

## 주관식 퀴즈 (뜻 직접 입력)

학생이 단어의 뜻을 직접 입력하면, **표준 답안과 글자가 달라도 뜻이 통하면 정답으로 인정**합니다.
채점은 100% 브라우저 안에서 이루어지며 **외부 API(구글 번역·검색 등)를 쓰지 않습니다.**
그래서 무료이고, 인터넷이 느려도 즉시 채점되며, API 키가 노출될 위험도 없습니다.

채점 방식은 `index.html` 안의 "주관식 채점기" 블록에 들어 있고, 다음을 조합합니다.

1. **정규화** — 공백·문장부호·괄호 주석·`~을/를` 같은 자리표시를 지웁니다. (`포기 하다.` = `포기하다`)
2. **뜻 분리** — 쉼표로 나열된 뜻은 각각 정답으로 인정합니다. (`버리다, 포기하다` → 둘 중 하나만 써도 정답)
3. **어간 추출** — 어미·조사를 벗겨 비교합니다. (`버림`·`버리다`·`버려서` → `버리`)
4. **동의어 사전** — 뜻 묶음 약 350개. (`포기하다` ↔ `단념하다` ↔ `그만두다`, `나중에` ↔ `추후에`)
5. **자모 편집거리 / 바이그램** — 오타를 흡수합니다. (`정확환` → `정확한`)
6. **오답 방지** — 같은 범위의 *다른 단어*의 뜻을 더 정확히 적었으면 오답 처리합니다.

판정 결과는 세 가지입니다.

| 판정 | 기준 | 화면 |
|---|---|---|
| ⭕ 정답 | 유사도 0.86 이상 | 바로 정답 처리 |
| 🤔 비슷함 | 0.60 ~ 0.86 | 모범답안을 보여 주고 학생이 `같은 뜻이에요 / 다른 뜻이었어요`를 직접 고름 |
| ❌ 오답 | 0.60 미만 | 모범답안 표시 + `선생님께 인정 요청` 버튼 |

기준값은 `index.html`의 `const ACCEPT=0.86, GRAY=0.60;` 에서 조절할 수 있습니다.
숫자를 낮추면 더 후하게, 높이면 더 엄격하게 채점합니다.

### 글자가 전혀 다른 동의어 — `alt` 로 해결

`나중에`와 `추후에`처럼 **글자가 하나도 겹치지 않는** 동의어는 편집거리·어간으로는
절대 잡을 수 없습니다. 뜻이 같다는 건 글자가 아니라 의미의 문제이기 때문입니다.
그래서 두 가지 장치를 둡니다.

**(1) 단어별 추가 정답 `alt`** — 가장 확실한 방법입니다.

```js
{w:"subsequently", p:"부", m:"그 뒤에, 나중에", alt:"추후에, 이후에, 뒤이어"},
```

`alt` 에 적은 표현은 뜻(`m`)과 똑같이 **100% 정답**으로 처리됩니다.
사전마다 뜻풀이가 달라 학생이 다르게 쓸 만한 단어에만 붙이면 됩니다.

**(2) 동의어 사전** — `SYN_GROUPS` 에 들어 있는 묶음은 모든 단어에 자동 적용됩니다.
시간·빈도·정도 부사, 접속어, 자주 쓰는 동사/형용사/명사를 넣어 두었습니다.

> 참고: 뜻이 다른 말은 여전히 오답입니다. 예를 들어 `subsequently` 에 `따라서`라고
> 쓰면 오답이고, 같은 범위에 `consequently` 가 있으면 "이 답은 consequently 의
> 뜻이에요"라고 알려 줍니다. 반대로 같은 범위의 다른 단어와 뜻이 겹치는 답
> (`achieve` 에 `달성하다`)은 "비슷함"으로 두어 학생이 직접 판단하게 합니다.

### 인정 답안이 쌓이는 방식

- 학생이 "비슷함" 구간에서 스스로 인정한 답 → 그 학생에게만 다음부터 자동 정답 (`kind: alias`)
- 오답 화면에서 보낸 인정 요청 → 선생님 확인 대기 (`kind: alias_req`)
- `admin.html` → 학생 → **✍️ 주관식 인정 답안** 탭에서 `전체 인정`을 누르면
  그 답이 **모든 학생**에게 정답으로 인정됩니다.

Supabase `progress` 테이블을 그대로 쓰며 스키마 변경은 필요 없습니다.
공통 인정 답안은 `student_key = "__ALIAS__"` 인 가상 계정 행으로 저장됩니다.

### 동의어를 더 넣고 싶다면

특정 단어에만 필요하면 `alt` 를, 모든 단어에 두루 쓰이는 말이면
`index.html`의 `SYN_GROUPS` 배열에 한 줄 추가하면 됩니다.

```js
["기부하다","기증하다","내놓다","희사하다"],
```

## 단어 추가

`index.html`의 `VOCAB_DATA` 를 편집합니다.
`w`(단어) · `p`(품사) · `m`(뜻) · `alt`(선택: 추가로 인정할 표현).
